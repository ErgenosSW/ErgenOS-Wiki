# Security

## Verify installation media

Match your ISO to the checksum published for its exact release. Download links are available on the [official website](https://ergenossw.github.io/ErgenOS-Website/).

## Review software sources

Use sources you understand and keep your system updated. The installer exposes optional software sources; their selection is documented under [updates and software](../system-administration/updates).

## Secure Boot

ErgenOS 1.1 has experimental post-install support. The installation ISO itself requires Secure Boot to be disabled. Read the [Secure Boot guide](./secure-boot) before making firmware changes.
