# Getting started

ErgenOS is an independent Arch Linux based distribution with GNOME, the linux-zen kernel and a graphical Calamares installer.

## Choose your next step

1. [Prepare and install ErgenOS](./installation).
2. [Complete your first boot](./first-boot).
3. Learn how [updates](../system-administration/updates) and [Btrfs snapshots](../recovery/snapshots) work.

## Scope of this guide

This initial wiki describes the ErgenOS 1.1 baseline documented in the project repository. Release-specific changes should be checked against the [release notes](https://github.com/ErgenosSW/ErgenOS-Linux/releases).

::: tip Start with the official image
Use the download links on the [ErgenOS website](https://ergenossw.github.io/ErgenOS-Website/). Verify the image against the checksum for that exact release.
:::

## Before you install

Back up important files, identify your target disk and check whether you need Btrfs recovery. See [hardware compatibility](../hardware/) for the current testing scope.
