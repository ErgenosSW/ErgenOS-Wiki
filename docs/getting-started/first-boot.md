# First boot

## Check the desktop

Sign in to GNOME and check your network, display, sound and input devices. Keep installation media available until normal boot works reliably.

## Update your system

Open ErgenPac to install system updates. ErgenOS uses the rolling release model and Arch repositories, together with its signed ErgenOS repository. Read [updates and software](../system-administration/updates) before adding more sources.

## Explore the ErgenOS applications

- **ErgenOS Welcome** provides the project's welcome experience.
- **ErgenCTL** includes system management and recovery tools.
- **ErgenPac** handles software and system updates.

## Check recovery

If your root filesystem uses Btrfs, learn about [Snapper and snapshot boot](../recovery/snapshots). Confirm your backup plan before relying on recovery features.

::: tip One change at a time
Check that the system boots and basic hardware works before changing drivers or configuring experimental Secure Boot support.
:::
