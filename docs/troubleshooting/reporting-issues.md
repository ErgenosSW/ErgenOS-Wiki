# Report a problem

## What to include

- ErgenOS release and computer model.
- Firmware mode and Secure Boot state.
- Root filesystem and software source selected during installation.
- Steps to reproduce the problem, expected result and actual result.
- Relevant Calamares or system journal output.

## Report template

```text
ErgenOS release:
Hardware:
UEFI / legacy mode:
Secure Boot enabled / disabled:
Root filesystem:
Software source:
Steps to reproduce:
Expected result:
Actual result:
Relevant logs:
```

::: tip Review logs before sharing
Remove passwords, tokens and personal information that are not needed to explain the problem.
:::

## Where to report

Report distribution issues in [ErgenOS-Linux issues](https://github.com/ErgenosSW/ErgenOS-Linux/issues). Documentation corrections belong in [ErgenOS-Wiki](https://github.com/ErgenosSW/ErgenOS-Wiki) once the repository is published. The edit link at the bottom of each article targets that article's language and source file.
