# Troubleshooting

## Start with the symptom

| Symptom | First check |
| --- | --- |
| Installation USB will not boot | Verify the image, UEFI boot entry and the release's Secure Boot limitations. |
| Optional software source setup fails | Check the internet connection and record the selected source. |
| System fails after an update | Identify the error and review Btrfs recovery availability. |
| A device does not work | Record the model and whether it worked in the live environment. |

## Keep the evidence

Record the exact error and the steps that triggered it before making additional changes. If the guide does not resolve the issue, [prepare a report](./reporting-issues).
