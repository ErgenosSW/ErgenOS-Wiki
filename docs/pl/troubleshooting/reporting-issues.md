# Zgłoś problem

## Co podać

- Wydanie ErgenOS i model komputera.
- Tryb firmware oraz stan Secure Boot.
- Główny system plików i źródło oprogramowania wybrane przy instalacji.
- Kroki odtworzenia, oczekiwany rezultat i rzeczywisty rezultat.
- Istotny fragment logu Calamares lub dziennika systemowego.

## Szablon zgłoszenia

```text
Wydanie ErgenOS:
Sprzęt:
Tryb UEFI / legacy:
Secure Boot włączony / wyłączony:
Główny system plików:
Źródło oprogramowania:
Kroki odtworzenia:
Oczekiwany rezultat:
Rzeczywisty rezultat:
Istotne logi:
```

::: tip Sprawdź logi przed udostępnieniem
Usuń hasła, tokeny i dane osobowe niepotrzebne do wyjaśnienia problemu.
:::

## Gdzie zgłaszać

Problemy dystrybucji zgłaszaj w [ErgenOS-Linux issues](https://github.com/ErgenosSW/ErgenOS-Linux/issues). Poprawki dokumentacji należą do [ErgenOS-Wiki](https://github.com/ErgenosSW/ErgenOS-Wiki), gdy repozytorium zostanie opublikowane. Odnośnik edycji pod artykułem prowadzi do pliku źródłowego w jego języku.
