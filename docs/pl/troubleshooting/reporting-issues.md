# Zgłoś problem

## Co podać

- Wydanie ErgenOS i model komputera.
- Tryb firmware oraz stan Secure Boot.
- Główny system plików i źródło oprogramowania wybrane przy instalacji.
- Kroki odtworzenia, oczekiwany rezultat i rzeczywisty rezultat.
- Istotny fragment logu Calamares lub dziennika systemowego.

## Szablon zgłoszenia

```text
Wydanie ErgenOS:
Sprzęt:
Tryb UEFI / legacy:
Secure Boot włączony / wyłączony:
Główny system plików:
Źródło oprogramowania:
Kroki odtworzenia:
Oczekiwany rezultat:
Rzeczywisty rezultat:
Istotne logi:
```

::: tip Sprawdź logi przed udostępnieniem
Usuń hasła, tokeny i dane osobowe niepotrzebne do wyjaśnienia problemu.
:::

## Gdzie zgłaszać

- [Zgłoś błąd ErgenOS](https://github.com/ErgenosSW/ErgenOS-Linux/issues/new?template=01-bug-report.yml).
- [Zaproponuj funkcję](https://github.com/ErgenosSW/ErgenOS-Linux/issues/new?template=02-feature-request.yml).
- [Przejrzyj istniejące zgłoszenia](https://github.com/ErgenosSW/ErgenOS-Linux/issues), zanim dodasz nowe.

Formularze przyjmują odpowiedzi po polsku i angielsku. Poprawki dokumentacji zgłaszaj w [ErgenOS-Wiki issues](https://github.com/ErgenosSW/ErgenOS-Wiki/issues); opiekun projektu wprowadza zmiany.
