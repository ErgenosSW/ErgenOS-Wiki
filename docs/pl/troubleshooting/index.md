# Rozwiązywanie problemów

## Zacznij od objawu

| Objaw | Co sprawdzić najpierw |
| --- | --- |
| Pendrive instalacyjny nie startuje | Sprawdź obraz, wpis UEFI i ograniczenia Secure Boot danego wydania. |
| Nie działa konfiguracja opcjonalnego źródła | Sprawdź internet i zapisz wybrane źródło. |
| System nie działa po aktualizacji | Zidentyfikuj błąd i sprawdź dostępność odzyskiwania Btrfs. |
| Urządzenie nie działa | Zapisz model i sprawdź, czy działało w środowisku live. |
