# Bezpieczeństwo

## Weryfikuj nośniki instalacyjne

Porównaj sumę ISO z sumą opublikowaną dla dokładnie tego wydania. Odnośniki do pobrania znajdziesz na [oficjalnej stronie](https://ergenossw.github.io/ErgenOS-Website/pl/).

## Sprawdzaj źródła oprogramowania

Korzystaj ze źródeł, których zasady rozumiesz, i aktualizuj system. Opcjonalne źródła dostępne w instalatorze opisano w [aktualizacjach i oprogramowaniu](../system-administration/updates).

## Secure Boot

ErgenOS 1.1 ma eksperymentalną obsługę po instalacji. Sam obraz instalacyjny wymaga wyłączenia Secure Boot. Przed zmianą ustawień firmware przeczytaj [poradnik Secure Boot](./secure-boot).
