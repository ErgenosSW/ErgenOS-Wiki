# Aktualizacje i oprogramowanie

## Korzystaj z ErgenPac

Używaj ErgenPac do aktualizacji systemu i aplikacji projektu. Przed zatwierdzeniem przejrzyj proponowane zmiany. Czytaj informacje o wydaniach, gdy aktualizacja zmienia instalację lub odzyskiwanie.

## Znaj swoje źródła

Instalator może skonfigurować wyłącznie oficjalne repozytoria, yay, paru lub Chaotic-AUR. ErgenOS nie utrzymuje osobnego binarnego mirrora pakietów Arch.

::: warning Dodatkowe źródła
Nie zakładaj, że pakiety z opcjonalnych źródeł przechodzą taką samą weryfikację jak pakiety oficjalne. Zapisuj, co dodajesz i skąd pochodzi.
:::

## Migawki podczas aktualizacji

Przy instalacji na Btrfs snap-pac tworzy migawki przed transakcjami Pacmana i po nich. W poradniku [migawki Btrfs](../recovery/snapshots) poznasz różnicę między uruchomieniem migawki a przywróceniem systemu.

## Gdy aktualizacja się nie uda

Zapisz dokładny błąd i unikaj dokładania niezwiązanych zmian. Przejdź do [rozwiązywania problemów](../troubleshooting/) i podaj w zgłoszeniu wybrane źródło oprogramowania.
