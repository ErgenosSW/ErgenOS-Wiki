# Pierwsze kroki

ErgenOS to niezależna dystrybucja oparta na Arch Linux, ze środowiskiem GNOME, kernelem linux-zen i graficznym instalatorem Calamares.

## Wybierz kolejny krok

1. [Przygotuj i zainstaluj ErgenOS](./installation).
2. [Skonfiguruj system po pierwszym uruchomieniu](./first-boot).
3. Poznaj [aktualizacje](../system-administration/updates) i [migawki Btrfs](../recovery/snapshots).

## Zakres poradnika

Pierwsza wersja wiki opisuje ErgenOS 1.1 na podstawie dokumentacji repozytorium projektu. Zmiany dotyczące konkretnego wydania sprawdzaj w [informacjach o wydaniach](https://github.com/ErgenosSW/ErgenOS-Linux/releases).

::: tip Oficjalny obraz
Korzystaj z odnośników na [stronie ErgenOS](https://ergenossw.github.io/ErgenOS-Website/pl/). Porównaj sumę kontrolną z sumą dla dokładnie tego wydania.
:::

## Przed instalacją

Zrób kopię ważnych plików, zidentyfikuj dysk docelowy i sprawdź, czy potrzebujesz odzyskiwania Btrfs. Zakres testów opisuje [zgodność sprzętowa](../hardware/).
