# Pierwsze uruchomienie

## Sprawdź pulpit

Zaloguj się do GNOME i sprawdź sieć, obraz, dźwięk oraz urządzenia wejściowe. Zachowaj nośnik instalacyjny, dopóki zwykły rozruch nie działa poprawnie.

## Zaktualizuj system

Otwórz ErgenPac i zainstaluj aktualizacje systemu. ErgenOS korzysta z modelu rolling release, repozytoriów Arch i własnego podpisanego repozytorium. Przed dodaniem kolejnych źródeł przeczytaj [aktualizacje i oprogramowanie](../system-administration/updates).

## Poznaj aplikacje ErgenOS

- **ErgenOS Welcome** to aplikacja powitalna projektu.
- **ErgenCTL** zawiera narzędzia administracji i odzyskiwania.
- **ErgenPac** służy do obsługi oprogramowania i aktualizacji.

## Sprawdź sterowniki

Otwórz Driver Manager w ErgenPac, aby wykryć procesor i kartę graficzną oraz zainstalować brakujące zalecane pakiety.

## Sprawdź odzyskiwanie

Jeżeli główny system plików to Btrfs, poznaj [Snapper i rozruch migawki](../recovery/snapshots). Ustal sposób wykonywania kopii zapasowych, zanim polegasz na funkcjach odzyskiwania.

::: tip Jedna zmiana naraz
Sprawdź zwykły rozruch i podstawowe urządzenia przed zmianą sterowników lub konfiguracją eksperymentalnej obsługi Secure Boot.
:::
