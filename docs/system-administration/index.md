# System administration

## Everyday management

ErgenOS combines Arch repositories with a signed ErgenOS repository for system integration and first-party applications. Start with [updates and software](./updates).

## Understand your installation

Keep a record of your ErgenOS release, root filesystem and software source selected in Calamares. These details affect available recovery options and help with troubleshooting.
